САЙТ «РОССИЯ ОНЛАЙН ХЭЛПЕР»
===========================

Что это
-------
Статический сайт приложения: витрина + живой поиск по базе + рабочее демо справочника.
Никаких сборщиков и интернета не нужно — обычные HTML, CSS и JS.

Файлы
-----
index.html        — главная: возможности, живой поиск, оверлей, кодексы,
                    установка, сценарии, горячие клавиши, роли, демо,
                    загрузка, планы, обновления, вопросы.
app.html          — демо справочника: копия приложения, работает в браузере.
data/articles.js  — компактный индекс 1006 статей для поиска на главной.
css/style.css     — все стили сайта.
js/main.js        — меню, появление блоков, подсветка разделов, поиск, копирование.
img/              — иконка, заставка и скриншоты оверлея.
app_icon.png      — иконка для app.html (демо).
moscow_hero.webp  — заставка для app.html (демо).
downloads/        — сюда можно положить архивы, если публикуешь сайт отдельно.

Как открыть
-----------
Просто открой index.html двойным щелчком — сайт работает по file://.
Если нужен локальный сервер:
  python -m http.server 8000
и открой http://localhost:8000

Живой поиск на главной
----------------------
- Работает полностью в браузере: data/articles.js загружает 1006 статей,
  поиск ищет по названию, краткому описанию и наказанию.
- Учитывает синонимы («угнали» → «угон»), отсекает служебные слова,
  редкие слова весят больше частых (IDF), есть небольшие приоритеты по кодексу.
- Клик по результату открывает нужную статью в демо:
  app.html?code=uk&i=84 — кодекс и номер статьи в базе.
- Можно подставить запрос ссылкой: index.html?q=угнали%20машину

Демо (app.html)
---------------
- Это копия index.html приложения со встроенной базой на 1006 статей.
- Работают: поиск, статьи, избранное, профиль, темы, палитры.
- Не работают в браузере: вход/аккаунты и оверлей — они только в Windows-версии.
- Поддерживаются ссылки вида app.html?code=uk (uk, pk, koap, pdd, tk, eth, fkz, con)
  и app.html?code=uk&i=84 — открыть конкретную статью.
- В правом нижнем углу демо есть кнопка возврата на главную сайта.

Как обновить демо после новой версии приложения
----------------------------------------------
1. Скопируй index.html новой версии в site/app.html.
2. Скопируй app_icon.png и moscow_hero.webp в папку site/.
3. Скопируй новую articles.json-выжимку: собери data/articles.js тем же способом
   (поля: [код, индекс, номер, название, краткое описание, наказание]).
4. Проверь, что в конце app.html остался блок <script> с кнопкой «Веб-демо»
   и поддержкой ?code=&i=.

Публикация (бесплатно)
----------------------
Сайт статический, поэтому подойдёт любой бесплатный хостинг.

1) GitHub Pages — бесплатно, без карты, адрес вида https://ник.github.io/rohelper/
   - Создай публичный репозиторий, например rohelper.
   - Загрузи содержимое папки site (файлы index.html, app.html, css, js, img,
     data, downloads, 404.html, .nojekyll) в корень репозитория.
   - Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
   - Через 1–2 минуты сайт откроется по адресу из раздела Pages.
   Ограничения: файл до 100 МБ, сайт до 1 ГБ, трафик ~100 ГБ/мес.
   Файл .nojekyll уже добавлен — он отключает обработку Jekyll.

2) Netlify Drop — без аккаунта и без git: https://app.netlify.com/drop
   Перетащи папку site в окно браузера — сразу получишь ссылку.
   Для постоянного адреса зарегистрируйся (бесплатно).

3) Cloudflare Pages — бесплатно и без лимита трафика:
   Workers & Pages → Create → Pages → Upload assets → перетащи папку site.
   Ограничение: файл до 25 МБ (наш архив 16,8 МБ проходит).

4) Vercel — через git-репозиторий или `npx vercel` (тоже есть бесплатный план).

Свой домен (например, rohelper.ru) можно подключить бесплатно на любом из них,
но сам домен покупается отдельно.

Файл 404.html — своя страница «не найдено» (работает на GitHub Pages и Netlify).
